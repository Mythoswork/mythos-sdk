# Mock integration apps

These reference implementations demonstrate the high-level API end to end.

| Stack | Repository | API demonstrated |
|---|---|---|
| Next.js | [mythos-calculator-mockup](https://github.com/Mythoswork/mythos-calculator-mockup) | `createMythos`, `mythos.handlers`, `useMythos`, `mythos.charge` |
| FastAPI | [mythos-sdk-python-mock-integration-app](https://github.com/Mythoswork/mythos-sdk-python-mock-integration-app) | `create_mythos`, `mythos.router`, `mythos.charge` |

Use the mock apps to inspect complete project structure and test a real dashboard launch. For a new integration, copy the smaller [framework quickstart](../resources/code-examples.md) rather than copying an entire mock application.
